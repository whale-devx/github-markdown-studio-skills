# Two edits before a commit

Use the guide supplied by the facilitator. You can answer on paper. Cite
the heading or passage that helped with each decision.

The last commit contains a one-line file named `hours.txt` with the text
`opens at 9`. You change the line to `opens at 10` and run
`git add hours.txt`. Then you change the line again to `opens at 11`
and save the file. You have made no other changes or commits.

1. A teammate wants to review the proposed commit. Which command would
   show its patch, and which two lines would they see removed and added?
2. You also want to check the edit you made after running `git add`.
   Which command would show that patch, and which lines would it compare?
3. Your editor approves `opens at 10` for today. You need to keep the
   later edit available for tomorrow. What command would you run, and
   what text would you find in the commit and in the file afterward?

If the guide does not answer a question for you, mark it unanswered.
