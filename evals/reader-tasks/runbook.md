# Release setup during a handover

Use the runbook supplied by the facilitator. This is a tabletop exercise.
Write the next action for each case and cite the passage that led you to it.

1. An established project has a semantic-release configuration and earlier
   release tags. A teammate asks you to run Git FlowKit's release scaffold
   with `--apply`. How do you proceed? What happens if the helper is invoked
   while that configuration is present?
2. A different project has one commit, no tags, no release configuration and
   no existing scaffold files. You may inspect the proposed setup. Give
   the CLI invocation, where the bootstrap boundary will be and what files
   you expect to find newly written after inspection. Use `<skill>` and
   `<repo>` as path placeholders.
3. The new project later receives permission to write the proposed local
   files. What further checks and decision are needed before its release
   workflow can run?

Submit your decisions, or mark a question unanswered if the runbook does
not give you enough information.
