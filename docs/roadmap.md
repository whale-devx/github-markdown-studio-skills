# Roadmap

[Home](../README.md)

## Initial implementation: v0.1.0

- [x] One installable skill covering repository Markdown beyond README.
- [x] Dark/light pairing guidance and a deterministic localized SVG generator.
- [x] English/Thai examples, glossary and translation-drift checks.
- [x] Capability-aware AI image-generation workflow and brief template.
- [x] Read-only local audit helper and regression suite.
- [x] Agent evaluation scenarios with explicit non-results status.

## Next validation work

- [ ] Exercise actual skill installation and invocation in selected supported agents.
- [ ] Verify rendered documents on GitHub in both themes and narrow layouts.
- [ ] Run host image generation/editing end to end with a real image tool.
- [ ] Extend language review beyond English and Thai, including native RTL review.
- [ ] Add a documented external-link checker with explicit network controls.
- [ ] Add optional Mermaid rendering checks against a recorded version.

## Comparative quality

- [ ] Run controlled comparisons against suitable README and diagram skill baselines.
- [ ] Include tutorials, reference pages and runbooks rather than only landing pages.
- [ ] Use blinded human review, held-out tasks, token/time costs and failure rates.
- [ ] Publish results, limitations and reproducible inputs before claiming superiority.

These are proposed tasks, not promises of background work or implemented capabilities.
